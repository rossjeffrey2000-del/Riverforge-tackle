# Riverforge Tackle — demo fishing shop

A responsive dark/premium storefront concept built with plain HTML, CSS and JavaScript. No build tools or paid software are required to preview it.

## Preview locally
1. Extract this folder.
2. Open `index.html` in a browser.
3. An internet connection is needed for the Google Fonts and remote demo photography.

## Important before taking real orders
This is a front-end demo, not a live e-commerce backend. The basket works in the browser, but checkout, card payments, inventory, shipping, tax, email sign-ups and order notifications are not connected. Products, images and prices are placeholders and must be replaced with accurate details for your real stock.

## Low-cost way to publish a preview
1. Create a GitHub account if you don't already have one.
2. Create a new public repository and upload `index.html`, `styles.css`, and `script.js`.
3. In repository Settings, open Pages, choose deployment from the `main` branch and `/ (root)`, then save. GitHub will provide a public preview URL.
4. For a custom domain, buy one from a domain registrar and follow the DNS instructions from your hosting provider.

Static hosting is suitable for a catalogue/preview. It is not enough by itself to securely take payments or manage orders.

## Cheapest realistic route to a working shop
- Start with the free preview to test the name, branding and product layout.
- If you need real orders, use an e-commerce provider that supports UK payments, delivery settings, order emails, refunds and legal policies. Compare monthly fees and transaction fees before committing; plans change.
- Connect a payment provider through the e-commerce platform's official integration. Never collect or store card details directly in this static site.
- Add real product photography, stock levels, shipping rates, returns policy, privacy/cookie information, terms, and a working contact email.
- If you are selling in the UK, check your consumer, tax and product-safety obligations before launch.

## Customising the demo
- Edit product names, prices, descriptions and image URLs in `script.js`, in the `products` array.
- Change branding and page copy in `index.html`.
- Change colours, spacing and layouts in `styles.css`. Main colours are set at the top in `:root`.

## Brand note
“Riverforge Tackle” is a suggested concept name, not a checked or registered trademark. Check company names, domains, and UK trademark availability before investing in branding.
